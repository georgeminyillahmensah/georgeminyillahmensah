### 🧭 About me

- 🛠️ **Lead Software Engineer** since 2022 — I lead a team of developers and have mentored 8 junior engineers.
- 🌍 **Digital Transformation Specialist** at the [Heritage and Cultural Society of Africa (HACSA)](https://thehacsa.org), building the platforms behind its programmes.
- 🎓 **Mastercard Foundation Scholar** at Ashesi University.
- 👩🏾‍💻 I teach tech to young women across Ghana through **Tech4Girls**, and I've coached high-school students in Python and robotics.
- 🏆 1st runner-up at the Ashesi Career Fair Coding Challenge and the Ashesi GDSC EduHack.

### 🚀 What I've built recently

| Project | What it does | Stack |
|---|---|---|
| **[Ashesi Housing System](https://ahs.ashesi.edu.gh)** | Hostel management for Ashesi University: room-group formation, booking under heavy concurrency, check-in/out with QR passes, fines and appeals, room changes, reporting. | FastAPI · React · TypeScript · PostgreSQL · Redis · Celery |
| **[Tech4Girls Hub](https://t4ghub.thehacsa.org/)** | Learning platform for HACSA's women-in-tech programme — 120+ trainees across 13 regions: cohorts, QR attendance, assignments, masterclasses, stipends. | FastAPI · React · TypeScript · PostgreSQL · Celery |
| **Elroi Healthcare Staffing** | Recruitment platform connecting nurses and allied health professionals with hospitals in Ireland. | FastAPI · React · PostgreSQL · Docker · Nginx |
| **[Shenice Marketplace](https://shenice.ie)** | Multivendor marketplace for students to buy and sell safely, with Stripe payments and live inventory. | FastAPI · React · PostgreSQL · Stripe |
| **HACSA Enterprise System** | Internal platform for performance management, task boards and multi-currency finance with payroll and audit logs. | Django · React · Redux · PostgreSQL |
| **Sankofa Summit 2026** | Event ticketing with Stripe checkout and webhook-confirmed orders, deployed on Azure. | FastAPI · React · Stripe · Azure |
| **[Centralized License Service](https://github.com/georgeminyillahmensah/Centralized-License-Service)** | License lifecycle and entitlement service shared across brands. | Python |

Most of this work lives in private client repositories — happy to walk through the architecture on a call.
